Privacy Policy

Effective date: October 25, 2026

TTRPG Production Studio is a privately operated workflow for producing tabletop roleplaying game PDF review proofs.

Google Drive data and permissions

When the owner authorizes Google Drive access, the workflow uses OAuth credentials to create versioned PDF review proofs and QA archives inside a specified folder in the owner's Google Drive. The currently requested https://www.googleapis.com/auth/drive scope technically permits broad Drive file access; the implemented upload script is intended to create files in the designated folder, not enumerate, modify, or delete existing files.

Processing and storage

The workflow runs via GitHub Actions. OAuth client credentials and the refresh token are stored as GitHub Actions encrypted secrets; short-lived access tokens are obtained from Google when needed. Produced PDF review artifacts and reports are stored on GitHub Actions and in the owner's Google Drive. GitHub and Google process data under their respective service terms.

Sharing and retention

The studio does not intentionally sell or share Google user data for advertising. Review artifacts are retained by the owner according to the project's production/archive procedures. GitHub Actions artifacts may have independent retention periods.

Control and revocation

The owner can revoke this app's Google account access from Google Account settings, delete uploaded files in Drive, and remove the OAuth credentials from GitHub Actions secrets. For questions or removal requests contact jthiboust2@gmail.com.

This site describes the current privately operated integration; permissions and retention may change when the implementation is updated.
